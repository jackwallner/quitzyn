## What survived, ranked by users reached times cost

1. **SM-4** Wrong currency symbol on every money figure for non-USD users, Pro screens and the free trial row.
2. **SM-5** Reminders stay off after the user allows notifications, until a later-day open or a check-in.
3. **SM-1** Back-logged slip into a pre-reset run: Longest overstated for good, live tree gains days.
4. **SM-2** Undo after a Reset: incoherent reversal, date-dependent, overlapping runs.
5. **SM-3** Slip and Undo past a year: permanent extra grove tree.
6. **SM-7** Unfolded Duo Timeline pane: stale draft can overwrite a saved note.

The audit ranked SM-7 fourth on "no known users"; with an unknown audience on one device it belongs last.

## Product calls and hazards

All ten product calls and three hazards match the code where checked (P1 SettingsView.swift:88 and OnboardingView.swift:913; P2 HomeView.swift:111 vs SobrietyService.swift:209-211 and GardenService.swift:292-300; P9 by grep, every named symbol has no caller). One adjustment: P3 (start date edit overlapping a closed run) has a citation after all, "Journeys must not overlap" (SobrietyService.swift:59), so it is a documented-invariant break the user triggers on purpose, not a pure product call. It stays uncounted here because the user chose the date.

No other serious state bug was found in the audit's scope.

## Method changes that would have prevented the errors

- Before citing one doc comment as the promise, grep AGENTS.md and the user-facing copy for the same rule. SM-2's "Undo should not be offered" contradicts AGENTS.md and TimelineView.swift:511.
- Write repro tests with the arguments the UI passes (`DateHelpers.startOfDay()` from SlipSheet, `.now` from Home), and vary the date by one day. The yesterday variant of SM-2 shows the worse outcome (overlapping runs) that the today-only test missed.
- For every route, list each screen that can reach the call and its bounds (SlipSheet's picker, Timeline's tap guard). The SM-1 route was right, but the audit did not say Home cannot reach it.
- For a "who sees it" estimate, grep every view that formats the value, not only the Pro ones (SM-4's free trial row).
- State cost from the self-heal trigger, not the best case (SM-5: "next check-in or later-day open", not "one morning").
- Assert the whole promise, not the first symptom. SM-1's test checked Longest and left the tree growth unasserted.
